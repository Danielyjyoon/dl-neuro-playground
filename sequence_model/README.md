# 🔁 Sequence Models (PyTorch)

This folder contains PyTorch-based practice code for building and training sequence models.  
The implementations are based on exercises from the **Sequence Models course** in the  
**DeepLearning.AI Deep Learning Specialization** (Coursera, taught by Andrew Ng).

> 🛠️ The original course uses Keras and TensorFlow.  
> All models here have been **re-implemented from scratch in PyTorch** for deeper understanding and hands-on practice.

---

## 📚 Included Topics

- ✅ Character-level RNNs
- ✅ Many-to-many LSTM sequence classifiers
- ✅ Sequence-to-sequence (Seq2Seq) models
- ✅ Attention mechanisms  
- 🔜 Transformer (Coming soon)
