# 🧩 CNN Practice (PyTorch)

This folder contains PyTorch-based practice code for convolutional neural networks (CNNs).  
It includes exercises from the **Convolutional Neural Networks course** in the  
**DeepLearning.AI Deep Learning Specialization** (Coursera, taught by Andrew Ng).

> 🛠️ The original course exercises are based on **Keras** and **TensorFlow**.  
> All implementations here have been **recreated from scratch in PyTorch** to deepen understanding and build hands-on experience.
