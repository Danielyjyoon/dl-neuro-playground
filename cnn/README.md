# 🧩 CNN Practice (PyTorch)

This folder contains PyTorch-based practice code for convolutional neural networks (CNNs).  
It includes exercises from the **Convolutional Neural Networks course** in the **DeepLearning.AI Deep Learning Specialization** (Coursera), as well as a customized **UNet** implementation used in a neuroimaging research project.

---

## 📂 Structure

### `basic_cnn/`
- PyTorch reimplementations of key exercises from the CNN course by Andrew Ng
- Topics covered:
  - Convolution and pooling operations
  - Padding, stride, filter size effects
  - Batch normalization and dropout
  - CNN training pipelines

### `nnUNet/`
- nnUNet used in WMH segmentation project
- Currently writing a paper, WMH segmentation from CT
